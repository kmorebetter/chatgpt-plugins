# The Compiler

Preserve the meaning of a request, turn it into concise instructions for the chosen AI or tool, and check the resulting work against the original goal. Includes clarification, compilation, evidence-based validation, and proposed reusable learning. Works with supplied context and available authorized tools. It does not run another model, guarantee outcomes, or automatically change files or external systems.

## Try it

- Help me turn this rough request into clear instructions for another AI.
- Check this result against my original request and identify what is still unverified.
- Explain what this completed run teaches us and whether any instruction should change.

No separate publisher account is required. Use the plugin in a supported ChatGPT or Codex session. For a new session, provide any prior working record or evidence you want to continue from.
