# Start a buyer research task

Explain that this workflow helps understand an organization and prepare useful questions from evidence. It ranks documented fit, not purchase intent, and never sends outreach itself.

If the request identifies one organization, use [buyer-brief](../buyer-brief/SKILL.md). If it asks for several accounts or a target list, use [target-book](../target-book/SKILL.md). Reuse information already supplied. Otherwise ask one question: are they preparing for a conversation with one company, or deciding which companies to approach?

No separate publisher account, API key, scraping service, or local software is required. Research uses available authorized tools or user-supplied material. Missing tools reduce what can be verified and must be disclosed.
