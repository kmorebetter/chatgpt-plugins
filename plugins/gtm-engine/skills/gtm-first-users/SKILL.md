# Plan the first customer experiment

Read [working method](references/working-method.md). Recover the audience, offer, capacity, budget and contact permissions. If material inputs are missing, ask for the one that blocks a useful plan.

Choose two channels from warm network, permitted communities, targeted individual outreach, content, and partnerships. Explain why each matches the user's reach. If only one is feasible within the user's capacity, say so and make the second a small optional test. Set modest daily or weekly quotas from available hours and effort per action. Do not use unsourced reply-rate benchmarks or prescribe spam volume.

Produce a 14-day dated table with channel, action, effort ceiling, and what to record. Include five problem interviews if that fits the experiment; otherwise state the feasible number. Never invent named targets or suggest that fit implies consent to contact. Targets can be roles or authorized organizations until identified through evidence.

Draft four messages per selected channel: opening, relevant follow-up, a clear invitation using approved offer terms, and a respectful follow-up to an expressed interest. Keep each under 90 words where appropriate, use the user's known voice, avoid false personalization and manufactured urgency, and stop after opt-out or rejection. For a public community, adapt the drafts to helpful posts and replies rather than unsolicited pitches. Mark every message as a draft. Sending is outside this workflow unless separately authorized through a supported tool.

Include tracking definitions: first contacts and follow-ups separately; substantive conversations; calls actually held; pilots actually started; payments actually received. Booked calls do not count as held calls. Unknown metrics are not zero. Update the plan and draft sections. Reminders are suggestions until an authorized scheduling tool confirms creation.
