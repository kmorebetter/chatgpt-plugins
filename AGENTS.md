# Plugin publication workspace

This folder owns the public versions of The Compiler, GTM Engine, and Buyer / Target Book. Original projects remain unchanged. Public packages contain reusable instructions and fictional examples only. Never copy client reports, contacts, private notes, credentials, or machine paths into a package.

`plugins/` is the distributable source. `docs/` is public product, privacy, support, and terms information. `review/` holds public fictional test fixtures and test records. `private/` and `dist/` stay untracked. Local validation is not an OpenAI scan or listing approval. Record submission IDs and actual portal states in `SUBMISSION-STATUS.md`; never infer success from an upload attempt.

Do not install global configuration or modify the original source projects. Use portable Agent Plugins manifests and skills. Keep the publisher name consistent with the verified identity selected in the portal. Verify all referenced URLs before submission.
