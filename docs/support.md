# Support

Publisher: Kerry Morrison. Contact: kmo@betterstory.co.

For The Compiler, GTM Engine, or Buyer / Target Book, include the plugin name, package version, the outcome you expected, and a redacted example of what happened. Do not send passwords, API keys, private customer records, or unredacted transcripts.

Common limitations:

- A plugin cannot grant access to unavailable tools, documents, or accounts.
- Research can proceed from supplied documents when browsing is unavailable. It must label unverified information.
- GTM Engine can produce a progress record in the conversation. To continue in a new chat, provide the last record or an explicitly saved file.
- Buyer / Target Book ranks documented fit and identifies unknowns. It does not establish that a company is ready to buy.

No hosted account or separate sign-in is required for these skills-only packages.
